# FluxBeacon

A simple FluxBeacon Service for event driven architecture.

With FluxBeacon, you get a lightweight tool that stays out of your way.

**What you get**

- A simple FluxBeacon Service for event driven architecture

## Key Features

- A simple FluxBeacon Service for event driven architecture

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/FluxBeacon.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

FluxBeacon is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
